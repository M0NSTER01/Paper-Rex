1) What this project is (purpose/domain)
This is a resume-to-portfolio web app (“SecondLife Resume” / “ResumeMagic”) that lets users sign up, upload a PDF resume, extract structured data with Gemini AI, edit it, choose a visual theme, and publish a shareable portfolio page.
